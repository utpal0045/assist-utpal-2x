About the project

ASSIST UTPAL 2X

A lightweight, mobile-first AI assistant website concept with a natural dark-green aesthetic. It separates the public frontend from the server-side AI key so the key does not need to be placed in browser code.

Frontend

HTML + CSS + JavaScript. Four independent pages with responsive mobile navigation.

AI Backend

Node.js + Express + OpenAI Responses API. Current-information questions can use web search.

Voice

Browser speech recognition for voice input and speech synthesis for reading answers aloud.

Important

AI answers can be incorrect. For important school, legal, medical or financial decisions, verify information with a trusted source or qualified adult/professional.
